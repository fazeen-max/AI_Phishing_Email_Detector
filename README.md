# AI Phishing Email Detector

## Overview
AI Phishing Email Detector is a Python-based project that analyzes email text and identifies suspicious phishing keywords. It helps users recognize potentially dangerous emails by assigning a risk level based on detected keywords.

## Features
- Detects common phishing keywords.
- Counts suspicious words in an email.
- Displays Low, Medium, or High risk level.
- Simple and beginner-friendly Python implementation.

## Technologies Used
- Python 3

- Git & GitHub
